# WAGRAM Frontend

Frontend WAGRAM dipisahkan dari repository backend `waTelegramConnector`.

Source of truth untuk implementasi awal: folder `miniapp/` pada branch `main` di repository `YosmerryGod/waTelegramConnector`.

Tujuan pemisahan ini adalah menjaga frontend tetap identik dengan Mini App yang sudah berjalan, tanpa mengubah desain, alur, atau kontrak API pada tahap ekstraksi.
